# Contributing to LiyaNG

شما می‌توانید به توسعه LiyaNG کمک کنید!

## مراحل:

1. Fork کنید
2. Branch جدید بسازید
3. Changes را commit کنید
4. PR ارسال کنید

## قوانین کدنویسی:

- Kotlin style guide پیروی کنید
- Test‌های مناسب بنویسید
- Commit messages را تشریح کنید

## Reporting Issues:

اگر Bug پیدا کردید:

1. Issue ایجاد کنید
2. تفاصیل شامل:
   - Android version
   - Device model
   - Steps to reproduce
   - Expected vs Actual behavior

## Questions?

در Issues پرسش کنید!
